# Web Development Final Project - Portfolio & Project Hub

This repository contains the final web development project created for the **6-Week Web Development Internship Program** at InternNova. It showcases a fully responsive developer portfolio with interactive project search, dynamic filtering, form validation, and modern layout design built using standard web technologies.

* **Live Website (GitHub Pages):** https://wdinternnovafinalharsh.vercel.app/
* **GitHub Repository:** [https://github.com/Harsh-Web-Developer/WD_Internnova_Final_Harsh](https://github.com/Harsh-Web-Developer/WD_Internnova_Final_Harsh)

---

## 🛠️ Project Features

1. **Responsive UI/UX Layout:** Built using modern CSS Grid and Flexbox, fully adaptable across mobile, tablet, and desktop screens.
2. **Dynamic Project Search & Filter:** Real-time client-side project filtering powered by JavaScript array methods (`filter`, `forEach`).
3. **Interactive Navigation:** Mobile hamburger toggle menu and smooth scrolling navigation.
4. **Form Handling & Validation:** Client-side event handling for the contact form with dynamic status updates.
5. **Clean Codebase:** Modular structure separating HTML, CSS, and JavaScript with semantic tags.
